# 📚 README - Migração SQLite → PostgreSQL

## 🎯 O Que É Isto?

**Solução completa e pronta para usar** que migra **todos os seus dados do SQLite para PostgreSQL de forma automática e segura**.

---

## 🚀 Comece Em 3 Passos

### 1. Configure .env
```ini
DB_HOST=localhost
DB_PORT=5432
DB_NAME=exodo_db
DB_USER=exodo_user
DB_PASSWORD=sua_senha
```

### 2. Execute Migração
```bash
python automatizar_migracao_completa.py
```

### 3. Verifique
```bash
python test_postgres_connection.py
```

**✅ Pronto! Dados no PostgreSQL!**
