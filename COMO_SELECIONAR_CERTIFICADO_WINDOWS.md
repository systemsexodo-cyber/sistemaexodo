# 🎯 COMO SELECIONAR CERTIFICADO DO WINDOWS

## ✅ IMPLEMENTAÇÃO CONCLUÍDA!

Agora você pode selecionar certificados diretamente do Windows Certificate Store no cadastro da empresa!

## 📋 COMO USAR:

### 1. **No Cadastro da Empresa:**

1. Vá em **"Empresas"** → **"Adicionar Empresa"** ou **"Editar Empresa"**
2. Role até a seção **"Certificado Digital"**
3. Você verá **DUAS opções**:

   **Opção 1 (RECOMENDADA):** 
   - Botão azul: **"Selecionar Certificado do Windows"**
   - Clique neste botão
   - Uma lista de certificados instalados no Windows será exibida
   - Selecione o certificado desejado
   - Digite a senha do certificado
   - Pronto! ✅

   **Opção 2:**
   - Botão branco: **"Selecionar Arquivo de Certificado"**
   - Para selecionar arquivo `.pem`, `.pfx`, etc.

### 2. **Pré-requisitos:**

- ✅ Certificado deve estar **instalado no Windows**
- ✅ Certificado deve estar no repositório **"Pessoal"** (CurrentUser\My)
- ✅ Certificado deve ter **chave privada** (HasPrivateKey = true)

### 3. **Instalar Certificado no Windows:**

Se o certificado ainda não está instalado:

1. **Duplo clique** no arquivo `.pfx`
2. Siga o **Assistente de Importação**
3. Selecione **"Localizar automaticamente o repositório"**
4. Digite a **senha** do certificado
5. Marque **"Marcar esta chave como exportável"** (importante!)
6. Clique em **"Concluir"**

## 🔍 VANTAGENS:

✅ **Não precisa processar arquivo** - Usa certificado já instalado  
✅ **Mais seguro** - Certificado fica no sistema  
✅ **Mais simples** - Sem conversão ou processamento  
✅ **Funciona automaticamente** - Sem dependências externas  

## ⚠️ IMPORTANTE:

- A opção **"Selecionar Certificado do Windows"** só aparece no **Windows**
- Se não aparecer certificados, verifique se estão instalados corretamente
- O certificado precisa ter chave privada para funcionar

## 🚀 TESTE AGORA:

1. Reinicie o app completamente
2. Vá em **"Empresas"** → **"Adicionar Empresa"**
3. Role até **"Certificado Digital"**
4. Clique em **"Selecionar Certificado do Windows"**
5. Selecione seu certificado
6. Digite a senha
7. Pronto! ✅
